Privacy Policy

Never Knew That Uploader · Last updated: 9 September 2026

What this application is

Never Knew That Uploader is a private, single-user automation. Its only function is to upload videos to the YouTube channel owned by its operator. It is not offered to the public, has no sign-up, and has no users other than the operator.

YouTube API Services

Never Knew That Uploader uses YouTube API Services. By using it, its operator is also bound by the YouTube Terms of Service. Google's own handling of any data it receives is described in the Google Privacy Policy.

Google user data we access

When the operator authorizes the application, it requests access to the YouTube Data API v3 using the following scopes:

  • youtube.upload — to upload video files to the operator's own channel
  • youtube — to set the title, description, tags, and privacy status of those uploads

The application accesses no other Google services. It does not read email, contacts, files, calendar, or profile data beyond the account identifier returned by the sign-in process.

How the data is used

The access granted is used for exactly one purpose: publishing videos the operator has produced to the operator's own YouTube channel. No data is read from, or written to, any other person's account.

How the data is stored

The OAuth access and refresh tokens issued by Google are stored encrypted in the operator's private n8n Cloud workspace, which is protected by the operator's own account credentials. No Google user data is copied to any other database, log, or storage system.

Sharing

Google user data is never sold, rented, transferred, or shared with any third party. It is not used for advertising, profiling, market research, or training machine learning models.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

The only Google user data this application holds is the OAuth access and refresh token pair for the operator's own account. Nothing else is retained: no profile data, no channel data, no analytics, no copies of uploaded videos beyond the upload request itself.

Those tokens are kept only for as long as the automation is in use. They are deleted when the operator deletes the credential from the n8n workspace or deletes the workflow, and they are invalidated immediately if access is revoked. There is no separate archive or backup from which they could be recovered.

The operator can revoke access at any time at myaccount.google.com/permissions. Revocation immediately and permanently ends the application's access, and the stored tokens become unusable.

Because the application has no users other than its operator, it holds no other person's data and there is no third-party deletion request to honour. Any request about this application can be sent to the address below and will be answered within 30 days.

Third-party content

Background footage used in the videos comes from Pexels and is credited to the original videographer in every video description. No Google user data is sent to Pexels or to any other content provider.
